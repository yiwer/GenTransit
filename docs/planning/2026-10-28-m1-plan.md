## 1. 范围

**做：**

- 工程骨架：pnpm monorepo、前后端应用、共享包、开发数据库、测试框架、代码规范。
- 登录：唯一内置账号、会话、登录限流、修改密码。
- 修改快照机制：记录、有效修改判定、修改历史弹窗、"已删除"视图。之后每个模块都用它。
- 基础数据：七类字典、行政区划、公交公司。
- 地标与地标类别（站点绑定地标要用）。
- 站点：列表、详情、新建与编辑（地图选点、逆地理编码建议、地标候选、照片、扩展字段）、删除、已删除视图。
- 设置：账号、方位模式、地标设置、扩展字段。
- 高德：前端加载 JS API；服务端代理 `/_AMapService`（附加安全密钥）；服务端调用 Web 服务做逆地理编码。
- 空站牌集：随站点创建、随站点删除（编辑器在 M3）。

**不做（留给后续里程碑）：** 线路的界面与接口（M2，但表结构在 M1 建好，见 3.3）；导入导出（M2）；站牌集编辑器、站架模板、工作台（M3）；只读 API 与 Token、Docker 部署与备份（M4）。

## 4. 快照机制

所有写操作都经过同一个 `SnapshotService.record(tx, { type, id, name, action, note, content })`，与业务写入在同一个事务里。

1. **内容构造：** 每类对象一个 `toSnapshot(entity)`（放在服务端，结构定义放 `packages/shared`）。产出自包含 JSON：引用的字典项、行政区划、地标、扩展字段定义都带上当时的 ID 和名称；扩展字段存为 `{ 键: { 字段名, 类型, 值 } }`。顶层带 `schema: 1`，以后结构变化时差异视图能按版本处理。
2. **规范化与比较哈希：** `normalize(content)` 去掉引用对象的名称、只留 ID；集合类（地标绑定）按 ID 排序；空字符串与 null 视为相同；对象键排序后序列化，取 SHA-256 作为 `compareHash`。**默认，可改**
3. **有效修改判定：** 新哈希等于该对象最后一份快照的哈希时，不写快照，也不更新业务行，接口返回"没有变化"。字典项改名不会让站点下一次原样保存产生快照，这与"不扩散"一致。
4. **新增与删除：** 新建站点时，站点与它的空站牌集各存一份"新增"快照；删除站点时两者各存一份"删除"快照。**默认，可改**
5. **差异：** `diffSnapshots(prev, next, spec)` 放在 `packages/shared`，按字段标签表输出字段级差异；列表类内容按 ID 对齐，输出增、删、移动、修改（M1 只用到站点，M2/M3 复用）。
6. **接口：** `GET /api/snapshots?type=&id=`（时间线，倒序，带差异所需的前一份内容）；`GET /api/snapshots/deleted?type=`（已删除视图）。
7. **界面：** 详情页与编辑器顶部的修改历史按钮 + 时间轴弹窗，按原型 `HistoryButton` 重写。

## 5. 并发保护（AC-10、BR-18）

- 站点、站牌集（以及 M2 的线路）带整数 `rev`。读取时返回 `rev`，保存时请求体带回。
- 更新语句 `UPDATE … WHERE id = ? AND rev = ?`，同时 `rev + 1`；影响行数为 0 时返回 409，响应里带最新内容。
- 前端收到 409 时弹窗"已在别处修改"，并排显示我的修改与最新内容的差异（复用快照差异组件），可选择"以最新内容重新编辑"。
- 字典、行政区划、公交公司、地标这类小对象不做 `rev`，后写覆盖。**默认，可改**

## 6. 认证与安全

| 项 | 做法 |
|---|---|
| 初始账号 | 启动时若 `Account` 为空，用 `GT_ADMIN_USERNAME`、`GT_ADMIN_PASSWORD` 创建；之后这两个变量不再生效 |
| 密码 | argon2id（`@node-rs/argon2`，有预编译包，Windows 免编译） |
| 会话 | 登录成功生成随机令牌，库里只存哈希；Cookie `gt_sid`，httpOnly、SameSite=Lax，HTTPS 下加 Secure；7 天滑动过期 **默认，可改** |
| 限流 | 连续 5 次失败锁定 15 分钟（需求第 11 节），计数存在 `Account` 上，重启不丢 |
| 改密码 | 需原密码；成功后注销其他会话 |
| 守卫 | 全局登录守卫，白名单只有登录接口、健康检查、前端静态资源 |
| CSRF | SameSite=Lax 之外，写请求要求 `Content-Type: application/json` 和自定义请求头 `X-GT-Request: 1` **默认，可改** |
| 校验 | 请求体用 `packages/shared` 里的 zod 模式，Nest 里用自定义 `ZodValidationPipe` |
| 上传 | jpg / png / webp，单张 ≤10 MB；文件存 `UPLOAD_DIR`；下载要登录会话（M4 起也接受 API Token）；M1 不生成缩略图 **默认，可改** |

## 7. 高德

| 能力 | 做法 |
|---|---|
| JS Key 下发 | 前端启动时请求 `GET /api/config`，拿到 `AMAP_JSAPI_KEY`。不在构建时注入，同一个镜像可以部署到不同环境 |
| 安全密钥代理 | Nest 实现 `/_AMapService/*`，规则沿用原型 `prototype/vite.config.ts`：`/v4/map/styles` → `webapi.amap.com`，`/v3/vectormap` → `fmap01.amap.com`，其余 → `restapi.amap.com`，转发时附加 `jscode`；要求登录会话，避免被当作公开代理 |
| 逆地理编码 | `GET /api/geo/regeo?lng=&lat=`，服务端用 `AMAP_WEB_SERVICE_KEY` 调高德 Web 服务，把返回的市、区、街道、道路先按名称精确匹配本库的行政区划与路段字典，再去掉"市 / 区 / 街道 / 镇"等后缀模糊匹配；匹配不到的作为"新建建议"返回，用户确认后才建（F-COM-07）**默认，可改** |
| 地图组件 | 按原型 `RealMap` 重写：高德底图（样式与暖色滤镜见设计语言第 3 节）+ 自绘 SVG 覆盖层；未配置高德或加载失败时退回示意坐标平面，端到端测试固定用示意模式，不依赖外网 **默认，可改** |
| 密钥不外泄 | 集成测试断言 `/api/config`、代理响应、前端构建产物里都不出现安全密钥与 Web 服务 Key（AC-18 在 M4 做完整验收） |

环境变量（`.env.example` 只写变量名）：`DATABASE_URL`、`SESSION_SECRET`、`GT_ADMIN_USERNAME`、`GT_ADMIN_PASSWORD`、`AMAP_JSAPI_KEY`、`AMAP_JSAPI_SECURITY_CODE`、`AMAP_WEB_SERVICE_KEY`、`UPLOAD_DIR`。启动时用 zod 校验，缺必填项直接退出并说明缺哪个；高德三个变量缺失时只是降级到示意地图并记警告。

## 9. 默认决定汇总（可改）

| # | 决定 | 理由 |
|---|---|---|
| 1 | 目录 `apps/web`、`apps/server`、`packages/shared` | 需求第 8 节的三分法 |
| 2 | React 19、NestJS 11、PostgreSQL 16；Prisma 版本见第 2 节 | shadcn/ui 当前以 React 19 + Tailwind v4 为准；本机 psql 客户端是 16 |
| 3 | 主键 UUID v7 | 有序、利于索引，导入导出不暴露自增序号 |
| 4 | 并发用整数 `rev`，只给站点、站牌集、线路 | 只有这三类有复杂编辑；小对象后写覆盖足够 |
| 5 | 有效修改比较时只看引用 ID、不看引用名称 | 改名"不扩散"，原样保存不产生快照 |
| 6 | 新建站点时空站牌集也存"新增"快照 | 站牌集时间线从头完整 |
| 7 | 列表地图只画当前页；"地图显示全部筛选结果"的开关以后需要再加（可用 MassMarks 一次画 2 万点） | M0 已定分页 + 地图一一对应；需求 7.1 已同步改写 |
| 8 | 字体自托管 | 内网部署不一定能访问外网字体服务 |
| 9 | 未配置高德时退回示意平面，端到端测试固定用它 | 测试不依赖外网和密钥 |
| 10 | M1 先建线路三张表，不做界面 | AC-09 在 M1 就能用真实外键验证 |
| 11 | 内部接口前缀 `/api`；M4 的只读 API 用 `/open/v1` | 两套鉴权分开，互不干扰 |
| 12 | 会话 7 天滑动过期；写请求要求自定义请求头 | 单用户内网工具，兼顾方便与 CSRF 防护 |
| 13 | 逆地理编码先精确匹配、再去后缀模糊匹配，匹配不到给"新建建议" | 不自动改用户已填的值，也不悄悄建字典项 |
| 14 | 照片不生成缩略图 | M1 规模下浏览器缩放足够，避免引入 sharp 原生依赖 |
| 15 | 高德 Web 服务 Key 变量名 `AMAP_WEB_SERVICE_KEY`；初始账号 `GT_ADMIN_USERNAME` / `GT_ADMIN_PASSWORD` | 需求 7.3 只规定了要有，没定名字 |

## 10. 风险

| 风险 | 应对 |
|---|---|
| Windows 上 Testcontainers 依赖 Docker Desktop 正常运行 | 本机 Docker 29 已在运行；CI 用 Linux |
| 中文字体体积大 | 按 unicode-range 分片加载；衬线体只用 600、700 两档 |
