# 不维护版本：只存当前事实，修改历史用整对象 JSON 快照

旧系统对站点、线路、站牌集维护版本链：每个版本是整个聚合的关系行拷贝，带生效日与失效日，支持版本分裂、合并、未来生效和按日期查询，系统的复杂度和派生缓存陈旧问题主要来源于此。决定业务表只存当前数据，保存即生效；每次有效修改（内容与上一份快照不同）对站点、线路或站牌集整体存一份自包含的 JSON 修改快照，只读查看前后差异，不可回滚，也不能按日期回看。

## Considered Options

- 保留版本链。
- 2026-05-30 轻量化探索中的 ChangeSet 工作区（预约生效、审核后应用）：本次范围不需要预约生效。
- 只记字段级操作日志：看不到修改时对象的完整样子。

## Consequences

- 以下旧能力不再存在：指定未来日期生效的修改、自动恢复的临时停运、提前为下月线路变化编排站牌、按日期差自动生成温馨提示、版本日历。
- 线路停运改为即时切换的状态；待编排与失效编排在读取时实时计算。
