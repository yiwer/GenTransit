# GenTransit 设计语言「导向 · 画室」

| 项 | 内容 |
|---|---|
| 状态 | 定稿 v2（M0 原型已确认），2026-10-28 |
| 实现位置 | 令牌 `prototype/src/styles.css`；组件 `prototype/src/ui/index.tsx`；灵动组件 `prototype/src/ui/lively.tsx` |
| 适用范围 | GenTransit 全部界面；M1 起按本文用 shadcn/ui 重建组件 |

**一句话：结构取自交通导向标识，气质取自晨光画室。**

## 1. 参考来源

| 来源 | 借鉴什么 |
|---|---|
| 交通导向标识（站牌、线路牌、地铁线路图） | 强层级；线路名是一块"牌"而不是一段文字；站序画成条形线路图 |
| Linear、Notion | 属性表代替表单；克制的分隔线；键盘可达 |
| Apple 地图 | 地图做底，信息卡片浮在上面 |
| `anthropic_svg.tsx`（用户提供） | 有机手绘笔触、1.5px 圆头描边、弹簧回弹缓动、暖纸色 |
| 画室视频（用户提供） | 亚麻奶油墙、原木棕、植物绿；深墨绿是唯一的深色 |

## 2. 五条原则

1. **像站牌一样清楚。** 一屏一个主角。站名、线路名用衬线大字；次要信息降成小号暖灰字。
2. **颜色只留给需要处理的事。** 纸与墨承载一切。赭石表示"待处理"，陶土表示"失效或危险"，鼠尾草表示"正常、完成"，珊瑚只用于灵动高光，墨绿只用于主操作和线路牌。
3. **地图是底。** 有空间属性的页面（站点、线路）一律左内容、右地图，信息卡浮在地图上。
4. **属性表代替表单。** 编辑和阅读用同一个版面：左边标签、右边取值。输入框平时像文字，悬停或聚焦才显出边框。
5. **动效是手写的、会回弹的。** 只出现在关键瞬间：保存成功、需要注意、等待、表示方向。系统设置"减少动效"时全部停止。

## 3. 色彩

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `paper` | #F3EEE5 | #171512 | 应用底色（带 22px 微颗粒） |
| `surface` | #FFFCF7 | #1E1B17 | 主工作面、卡片 |
| `surface-2` | #FAF6EF | #221F1A | 次级面、表头、页脚 |
| `sunken` | #EDE6D9 | #2A2620 | 输入底色、悬停底色 |
| `hairline` / `hairline-2` | 棕 12% / 22% | 暖白 8% / 16% | 分隔线 / 描边 |
| `ink` → `ink-4` | #221C15 / #574C40 / #72665A / #A69A8A | #EFE8DC / #C4BAAA / #9D9282 / #6E655A | 正文 → 占位；`ink-4` 只用于装饰和占位 |
| `accent`（墨绿搪瓷） | #1F4547 | #8DBAB4 | 主按钮、选中、焦点环 |
| `plate` | #1F4547 | #D6E6E1 | 线路牌底色（深色模式反相） |
| `signal`（赭石） | #C8902E · 底 #F5E6C6 · 字 #6A4A10 | #E2AE4A | 待编排、未保存、需要注意 |
| `danger`（陶土） | #B4502F · 底 #F6DDD2 | #E58A6C | 失效、删除 |
| `sage`（鼠尾草） | #5A7A68 · 底 #DFE7DF | #8FB09B | 运营中、已编排、地标、完成 |
| `coral`（珊瑚） | #D97757 | #E8906F | 灵动高光：选中涟漪、线路流动、印章对勾 |

地图另有一组令牌（`map-land`、`map-block`、`map-water`、`map-park`、`map-road`、`map-road-major`、`map-casing`、`map-label`），色相与纸面一致，用于示意地图。

**高德底图：** 浅色用 `amap://styles/whitesmoke`、深色用 `amap://styles/dark`，只开 `bg`、`road`、`building` 三类要素（不显示 POI，避免和地标打架），再给底图容器加暖色滤镜（浅色 `sepia(0.28) saturate(0.78) hue-rotate(-8deg) brightness(1.03) contrast(0.96)`），让街道图落进纸面色调。站点、线路、涟漪、流动、定位标记不用高德覆盖物，而是由我们自己的 SVG 覆盖层绘制，滤镜只作用于底图。高德 logo 与版权信息必须保持可见，浮动卡片放在地图右下角或左上角，不压住左下角。

## 4. 字体

| 角色 | 字体 | 用在哪里 |
|---|---|---|
| 标题与名称 | Noto Serif SC（思源宋体）600–700 | 页面标题、站名、首末站、地图上的站名 |
| 界面正文 | Plus Jakarta Sans + Noto Sans SC | 其余所有文字，基础字号 14px，数字等宽 |
| 线路牌 | Barlow Condensed 600 | 线路牌上的线路名 |
| 代码与坐标 | JetBrains Mono | 经纬度、编号 |

小标签（eyebrow）：11.5px、字重 600、字距 0.08em、`ink-3`。

## 5. 形状、层次与质感

- **圆角：** 控件 8px，卡片与浮层 14–16px，主工作面 18px，标签与筛选 9999px，线路牌 3–10px（随尺寸变化）。
- **层次：** 用细线和三档阴影（`shadow-xs` 贴面、`shadow-float` 浮于地图、`shadow-pop` 弹出层），不用粗边框。
- **质感：** 纸底有 22px 间距的微颗粒点阵；主工作面是一块圆角"纸"浮在底色上。

## 6. 识别符号

| 符号 | 规则 |
|---|---|
| 线路牌 `RoutePlate` | 墨绿底、奶油白字、窄体粗字。尺寸 xs / sm / md / lg / xl。四种状态：正常；停运（虚线描边加删除线）；失效（陶土底加删除线）；幽灵（描边，用于换乘提示） |
| 方位章 `DirBadge` | 方框里一个字，像站牌上的方向标；跟在站名后面 |
| 状态章 `StatusChip` | 待编排 = 赭石底加呼吸点；已编排 = 鼠尾草；隐藏 = 虚线框；失效 = 陶土。颜色永远配文字，不靠颜色单独传达 |
| 线路条形图 | 竖线是墨绿轨道，首末站是带珊瑚芯的实心圆，中间站是空心圆；右侧用幽灵线路牌列出换乘线路 |
| 品牌标 | 一块墨绿站牌，挂一枚会呼吸的珊瑚色站点 |

## 7. 版式

- **外壳：** 不要顶栏。导航、搜索、主题、账号都收进左侧 216px 窄栏，高度全部留给内容和地图。
- **分栏（站点列表、站点详情、线路列表、线路详情、站点表单）：** 左内容、右地图。分隔条可拖动，左栏最小 360px，最大占 62%；宽度记在本浏览器。地图可收起；左栏宽度不小于 760px 时，列表切换为宽表。
- **详情页：** 顶部是返回链接和操作按钮；然后是衬线大标题、方位章、英文名（斜体）、位置信息；分节依次为经过线路、站牌集、位置、站台设施、其他、照片、修改历史。
- **表单：** 分节用属性表；底部固定一条状态栏，显示"未保存：改了哪些字段"。
- **分页：** 列表底部固定一条分页栏："第 1–20 个，共 32 个" + 页码（首末页、当前页前后各一页，其余用省略号）+ 每页条数（10 / 20 / 50 / 100）。当前页用墨绿实心块。页码和每页条数写进 URL；筛选条件变化时回到第 1 页。地图只画当前页的对象，和列表一一对应。左栏较窄时页码收成"1 / 2"。
- **地图联动：** 列表或站序里单击一项 = 在地图上定位并高亮（右下角浮出小卡片）；双击或回车 = 进入详情页。单击不跳页，避免用户在浏览时被带走。
- **站牌编排编辑器：** 上方是站台立面：站架按页面宽度自动折行，比例分紧凑 / 标准 / 大三档（最高一块牌显示 230 / 320 / 430px）。候车亭画顶棚，立柱和地面线表示安装方式。站牌是"实物"样式：浅金属渐变边框、墨绿牌头（编号 + 朝向 + 类型与数量）、线路行用虚线分隔；行内容按牌面宽度分三级（窄：线路牌 + 方向；中：加终点站；宽：加序号和"开往"）。插片是嵌入面板，左上角有墨绿号码小标签，非线路插片用斜纹。下方托盘只有两个区：待编排（往上拖到站牌；站牌上的线路拖回来即移除）和隐藏（虚线框的独立投放区，拖进去即隐藏）。已编排直接看站牌，失效编排在站牌上标红，工具条右侧一键清理。托盘可收起，腾出高度看多行站架。
- **修改历史：** 平时只是详情页顶部的一个按钮（叠纸图标 + 快照数量，本次会话有新快照时数量变珊瑚色）。点开是弹窗时间轴：左列日期与时间，中间轨道与圆点（新增 = 鼠尾草，删除 = 陶土，本次会话 = 珊瑚带涟漪，其余 = 墨绿），右列动作标签、摘要和可展开的字段差异（旧值删除线陶土色，新值鼠尾草色）。

## 8. 灵动组件

| 组件 | 出现场景 | 动作 |
|---|---|---|
| 印章对勾 `SealCheck` | 保存成功、生成快照的提示 | 波浪印章回弹出现，珊瑚色对勾一笔写出 |
| 轨道加载 `OrbitLoader` | 逆地理编码等短暂等待 | 双椭圆轨道反向旋转，中心四芒星呼吸 |
| 呼吸点 `BreathingDot` | 列表里的待编排、失效计数 | 圆点向外扩散涟漪 |
| 快照叠纸 `SnapshotStack` | 修改历史标题 | 悬停时三张纸散开 |
| 选中涟漪 | 地图上选中的站点、编辑中的定位标记 | 珊瑚色涟漪交替扩散 |
| 线路流动 | 地图上被强调的走向 | 珊瑚色短划沿行驶方向流动 |
| 空状态插画 | 没有站架、没有搜到结果 | 手绘站牌缓慢浮动；放大镜外有轨道缓慢转动 |

动效令牌：`--spring: cubic-bezier(0.22, 1, 0.36, 1)` 用于移动和展开；`--bounce: cubic-bezier(0.34, 1.56, 0.64, 1)` 用于小的确认动作；进场 0.45s，回弹 0.6s，循环动效 2–3s。

## 9. 可访问性

- 正文与背景对比度至少 4.5:1（`ink-3` 在纸底上约 4.7:1）；`ink-4` 不用于承载信息的文字。
- 焦点环：2px 墨绿实线，偏移 2px。
- 状态同时用颜色、文字和形状（虚线、删除线）表达，不只靠颜色。
- 所有拖拽操作都有不拖拽的替代（"放到…"菜单）。
- `prefers-reduced-motion: reduce` 时停止所有循环动效，进场动效瞬间完成。

## 10. 不要做的事

- 不要用通用后台的默认表单观感：灰框输入、蓝色主按钮、每个字段一个卡片。
- 不要用纯黑纯白、冷灰、霓虹色、大面积渐变。
- 不要用 emoji 当图标；图标统一用 1.6px 线性图标（lucide）。
- 不要让动效常驻在正文区域；循环动效只能出现在"需要注意"的小元素上。
- 不要把线路名写成普通文字；凡出现线路名，一律用线路牌。

## 11. 落地到 M1

- 把第 3 节的令牌写进 Tailwind v4 `@theme`，同时映射到 shadcn/ui 的 CSS 变量（`--background`、`--primary`、`--ring` 等）。
- 用 shadcn/ui 重建 `Button`、`Input`、`Select`、`Popover`、`Dialog`、`Sheet`；`RoutePlate`、`DirBadge`、`StatusChip`、`Prop`、`SplitView` 和灵动组件作为项目自有组件。
- 高德底图按第 3 节的样式与滤镜接入，覆盖层自绘；可再在高德控制台做一套自定义样式替代滤镜，配色按地图令牌。
