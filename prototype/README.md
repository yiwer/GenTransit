### 高德底图

开发服务器启动时读取两个环境变量（系统环境变量，或复制 `.env.example` 为 `.env.local` 后填写）：

| 变量 | 去向 |
|---|---|
| `AMAP_JSAPI_KEY` | 注入前端，用于加载 JS API 2.0（Key 本身会出现在浏览器里，请在高德控制台绑定域名白名单） |
| `AMAP_JSAPI_SECURITY_CODE` | 只留在开发服务器：`/_AMapService` 代理转发高德服务请求时附加 `jscode`，前端只设置 `serviceHost`，浏览器拿不到 |

两个变量都有时用高德底图（暖色滤镜 + 自绘覆盖层）；缺任何一个，或加载失败，自动退回示意地图。改了变量需要重启开发服务器。

注意：示例数据是虚构的"示例市"，坐标落在杭州附近，所以站点不在真实道路上，有的甚至在江里。线路按站序直线连接。

|---|---|---|

编辑器的淘汰方案仍可用 `?variant=A|A1|A2` 临时查看，与 A3 共用同一份草稿。

## 建议试的操作

- 站点列表：拖动中间分隔条；点"收起地图"看宽表，再点右下角"展开地图"；点一个站点看地图上的涟漪和浮卡；双击或点 ↗ 进入详情；底部分页（地图只画当前页），切换每页条数，再加个筛选看它回到第 1 页。
- 站点详情：悬停"经过线路"里的某条线路，地图上点亮它并显示行驶方向的流动；点顶部"修改历史"看时间轴弹窗并展开差异；在"更多"里删除「体育中心」（没有线路经过）。
- 线路详情：切换上行/下行；单击站序里的站点让地图定位过去，双击（或回车）进入站点详情；点"停运"后去 `/sign-sets/s01` 看 1 路编排变成失效，再回来恢复运营。
- 站点表单：在地图上点一下，看轨道加载和地址建议；把方位改成"西"看重名提示；字段平时像文字，悬停才显出输入框。
- 站牌集编辑器：拖线路到站牌和插片；选中一号牌自动排序；保存一次看印章对勾提示，不改内容再保存提示"没有变化"。
- 左下角切换深色主题。

## 刻意的简化

- 站点坐标是编造的，只用来演示交互；逆地理编码仍用假规则（为了和示例字典一致），没有调用高德接口。
- 线路表单、导入、导出、修改历史差异只弹提示，不做流程。
- 未保存拦截只拦截页面内链接和刷新，不拦截浏览器后退。
